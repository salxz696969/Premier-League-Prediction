    How these numbers are calculated

    Three steps, using the model's real values for this fixture. The numbers at each step lead exactly to the percentages above.

    1Expected goals for each team

    How is each "×" worked out?

    The model learned one weight per input from 9,000+ past matches (a Poisson regression). For this fixture it measures how unusual each input is: z = (value − average) ÷ spread. The effect of that input is eweight × z: above 1 raises the expected goals, below 1 lowers them. Some inputs overlap (three of them are based on Elo), so one weight on its own can look odd; only their combined effect matters.

    2From expected goals to the chance of each number of goals

    Goals in football follow a Poisson distribution (Maher, 1982): if a team is expected to score λ goals, the chance it scores exactly k is λk × e−λ ÷ k!

    3Every exact score, then add them up

    The chance of a score is home chance × away chance, e.g. . Adding up all the scores where the home team has more goals gives the home-win chance, and so on.

    +The Elo rating, one of the inputs

    Elo's expected score counts a draw as half a win. It feeds into step 1 as an input; it isn't the final answer on its own.

    Expected starting eleven

    Each player's FPL influence per 90 minutes over his last 15 games. The model adds these up to rate the whole team.

    Line-ups aren't announced until an hour before kick-off, so each team's 11 most-used starters from its last 5 league matches are assumed.

      Precision
      When the model picks this result, how often is it right? correct picks ÷ all picks of it
      Recall
      Of all matches that really ended this way, how many did the model pick? correct picks ÷ real cases

      One number combining both: 2 × precision × recall ÷ (precision + recall)

        Method

        How it works

        Four steps from raw data to a prediction, with one rule throughout: only use what was known before kick-off.

        1. 1

          Data

          Every Premier League match from 2000-01 to 2025-26: results, shots, shots on target, corners, fouls and cards, checked automatically. Plus every FA Cup, League Cup, Champions League and Europa League match of these clubs, international breaks, and Fantasy Premier League player data from 2016-17.

        2. 2

          Features

          49 inputs per match, all from earlier matches: Elo rating, form over the last 5 games, weighted goals and shots, league position, last season's finish, rest days and head-to-head. An automatic test changes results and checks that no earlier input moves.

        3. 3

          Models

          Baseline, Elo only, logistic regression, random forest, gradient boosting, a Poisson goals model and an ensemble. Each one outputs a probability for home win, draw and away win.

        4. 4

          Testing

          Walk-forward: to predict a season, train on all seasons before it. 12 test seasons, 4,560 matches. Bookmaker odds are the benchmark only and are never a model input.
